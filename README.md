# Cisco-Networking-Labs
Packet tracer labs for networking practice

Cisco Networking Labs

A collection of hands-on networking projects created using Cisco Packet Tracer to develop practical networking, configuration, and troubleshooting skills.

Lab 01: Home Network Setup

Project file: "Home-Network-Lab.pkt"

Project Overview

Designed and configured a simulated home network connecting wired and wireless devices through a wireless router and Cisco 2960 switch.

Network Devices

- 1 wireless home router
- 1 Cisco 2960 switch
- 2 wired PCs
- 2 wireless laptops
- 1 smartphone
- 1 server
- 1 wireless security camera

Configuration

- Configured DHCP for automatic IPv4 address assignment.
- Configured wireless networking with WPA2-PSK security.
- Connected wired devices through the switch.
- Connected wireless devices to the home router.
- Verified network connectivity using ICMP ping tests.

Network Details

- Network: 192.168.0.0/24
- Default gateway: 192.168.0.1
- Server IP: 192.168.0.106
- Camera IP: 192.168.0.107

Results

Successfully tested communication between wired and wireless devices, including the security camera.

Tools Used

- ICMP
